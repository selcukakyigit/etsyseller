# Supabase e-posta şablonları

Üretildi: `python backend/scripts/build_supabase_emails.py`. Supabase > Authentication > Emails > Templates.

| Şablon | Konu satırı |
|---|---|
| `confirm_signup.html` | Confirm your Ulagg account / Ulagg hesabını doğrula |
| `recovery.html` | Reset your Ulagg password / Ulagg şifreni sıfırla |
| `magic_link.html` | Your Ulagg sign-in link / Ulagg giriş bağlantın |
| `email_change.html` | Confirm your new email / Yeni e-postanı doğrula |
| `invite.html` | You're invited to Ulagg / Ulagg'a davet edildin |
| `reauthentication.html` | Your Ulagg confirmation code / Ulagg doğrulama kodun |
